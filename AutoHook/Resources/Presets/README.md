# Bundled ocean fishing presets

Source: PunishXIV/AutoHook wiki, `Ocean-Fishing.md`, revision
`c3dc6b55fb1407232fdc5f59eb974a1ea388c233` (2026-05-27).

https://github.com/PunishXIV/AutoHook/wiki/Ocean-Fishing/c3dc6b55fb1407232fdc5f59eb974a1ea388c233

The markdown is preserved verbatim apart from line endings. It contains 32
individual AH3/AH4 presets and 7 AHFOLDER exports with 35 further presets.
Keep its instructions available when choosing bait, GP requirements, routes,
weather and spectral-current variants. These are historical community presets;
they do not implement AH6 Ocean V3 automatic route/strategy selection.

The API13 fork embeds this snapshot so community imports remain available
offline and after upstream wiki removal. Loading only displays available
presets; the user imports chosen presets through the existing community UI.
Do not replace this file with AH6 exports without checking the API13 importer
and fishing condition/action implementations.
